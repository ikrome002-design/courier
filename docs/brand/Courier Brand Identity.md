# Full Brand Identity System

# **Courier by Citrus**

**Product owner:** Citrus Labs Limited
**Primary product name:** **Courier by Citrus**
**Short product name:** **Courier**
**Product category:** Delivery Management SaaS / Courier Operations Platform
**Core audience:** Merchant courier businesses, package senders, and package recipients.

Courier by Citrus is not simply a courier app. It is a SaaS operating layer for transport service providers: delivery request intake, quote/pricing, dispatch, driver assignment, route visibility, delivery tracking, proof of delivery, billing, reporting, and administrator oversight. The project scope confirms that the transport provider is the primary operational user, while senders and recipients mainly interact with the platform to create, track, confirm, and acknowledge deliveries.

# 1. Brand Strategy Foundation

## Brand Essence

# **Clear delivery, warmly handled.**

Courier by Citrus should feel like a calm, capable system sitting behind every delivery. It should reassure the business that operations are under control, reassure the sender that their package is visible, and reassure the recipient that receiving the delivery will be simple.

## Core Brand Promise

**Courier by Citrus helps courier businesses manage every delivery clearly, while giving senders and recipients a warmer, simpler, more trustworthy delivery experience.**

## Strategic Positioning

# **Professional courier management software with a human delivery experience.**

This is the strongest positioning because it balances both sides of the product:

* **Merchant courier businesses** need control, dispatch visibility, proof, billing, and reports.
* **Senders** need confidence, simplicity, and updates.
* **Recipients** need clarity, ETA visibility, and easy confirmation.

The brand should not sound like a cold logistics backend. It should also not sound like a casual consumer courier company. It should sound like a modern SaaS product that makes courier operations feel more organized, more transparent, and more human.

# 7. Visual Identity System

The latest generated logo direction is substantially stronger than the earlier green version. The warmer palette gives the brand more character, better emotional appeal, and a more memorable SaaS feel.

## Logo Concept

# **The Courier Loop**

The logo mark should be interpreted as a **delivery loop**: a flowing “C” shape that represents movement, continuity, and completion.

## Symbol Meaning

| Logo Element                      | Meaning                                           |
| --------------------------------- | ------------------------------------------------- |
| **Ribbon-like C shape**           | Courier, connection, route, movement, continuity. |
| **Parcel cue in negative space**  | Package handoff, delivery, goods in transit.      |
| **Warm verification badge/check** | Proof of delivery, trust, confirmation.           |
| **Rounded geometry**              | Human, approachable, simple.                      |
| **Plum/coral/apricot palette**    | Warmth, sophistication, energy, friendliness.     |

## Logo Personality

The logo should feel:

* Warm but not childish.
* Premium but not corporate-cold.
* Simple but not generic.
* Operational but not mechanical.
* SaaS-ready but not sterile.

## Logo Lockups

| Lockup                      | Use                                                       |
| --------------------------- | --------------------------------------------------------- |
| **Primary horizontal logo** | Website header, landing pages, proposals, social banners. |
| **Stacked logo**            | Presentation covers, onboarding screens, posters.         |
| **Symbol only**             | Favicon, app icon, mobile nav, loading screen.            |
| **Wordmark only**           | Minimal UI surfaces and footer usage.                     |
| **Monochrome logo**         | Contracts, invoices, black-and-white print.               |

## Logo Usage Rules

* Keep clear space around the logo equal to at least the height of the verification badge.
* Do not place the logo on visually noisy backgrounds.
* Do not recolor individual elements randomly.
* Do not stretch or compress the mark.
* Do not use the favicon mark with the full wordmark at tiny sizes.
* Use the full **Courier by Citrus** lockup on public-facing materials.
* Use the symbol-only mark inside the app where space is limited.

# 10. Iconography Guidelines

## Icon Style

Use a custom rounded-line icon system inspired by the logo’s ribbon geometry.

## Rules

* Rounded corners.
* 2px stroke on standard UI icons.
* Minimal linework.
* Avoid generic filled clipart.
* Avoid thin, fragile icons.
* Use the same curve softness as the logo.
* Active icons may use Handoff Coral or Courier Plum.
* Status icons must pair with text labels for accessibility.

## Core Icon Set

| Feature           | Icon Concept                                   |
| ----------------- | ---------------------------------------------- |
| Delivery request  | Soft parcel outline + plus                     |
| Dispatch          | Route loop + assignment dot                    |
| Driver            | Person marker + route line                     |
| Vehicle           | Simplified vehicle silhouette, not too literal |
| Tracking          | Curved route path                              |
| Proof of delivery | Seal/check badge                               |
| Quote             | Receipt + small route                          |
| Payment           | Card/receipt                                   |
| Reports           | Rounded bar chart                              |
| Failed delivery   | Alert badge                                    |
| Recipient         | Person + receiving mark                        |
| Sender            | Hand-off parcel mark                           |
| Tenant/provider   | Storefront/building outline                    |

## Favicon/Icon Rules

The favicon should use the symbol only. At very small sizes, simplify it:

* Keep the bold “C” ribbon.
* Keep the parcel negative space only when legible.
* Keep the proof badge only at 32px and above.
* At 16px, use simplified “C” ribbon + warm badge dot, no detailed check.

# 17. Brand Governance

## Logo Dos

* Use the full-color logo on white or cream backgrounds.
* Use the symbol-only mark for app icons and favicons.
* Use plum wordmark for strong contrast.
* Use coral/apricot accents for warmth and motion.
* Preserve negative space inside the icon.

## Logo Don’ts

* Do not return to the dull green palette as the primary identity.
* Do not add vans, motorcycles, wings, or generic pins.
* Do not place the full logo over busy photography.
* Do not use the check badge as a standalone logo.
* Do not use gradients excessively across the UI.
* Do not make the icon too detailed at favicon size.

## Copy Dos

* Use simple, reassuring language.
* Say exactly what happened.
* Tell the user what happens next.
* Use “delivery,” “package,” “driver,” “recipient,” and “proof” naturally.

## Copy Don’ts

* Do not use heavy logistics jargon for senders and recipients.
* Do not sound robotic.
* Do not overpromise automation.
* Do not hide failed delivery states behind vague wording.
